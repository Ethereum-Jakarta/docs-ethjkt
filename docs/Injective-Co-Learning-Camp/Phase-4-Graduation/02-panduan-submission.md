## 1️⃣ Link Profil HackQuest

Masuk ke [hackquest.io](https://www.hackquest.io), buka profilmu, dan salin URL dari address bar.

**Yang benar:** URL profil publik yang bisa dibuka orang lain
**Yang salah:** URL halaman dashboard atau setting yang hanya bisa kamu akses

:::warning Uji di jendela penyamaran
Buka jendela penyamaran, tempel URL-nya. Kalau kamu diminta login, itu bukan tautan publik.
:::

---

## 2️⃣ Screenshot Learning Track 100%

Ini bukti yang paling teliti diperiksa. Buat yang benar.

**Screenshot harus memperlihatkan:**
- Nama atau username-mu
- Indikator penyelesaian **100%**
- Nama camp atau learning track
- Idealnya kesembilan phase terlihat tercentang

**Cara membuat yang baik:**

| Lakukan | Jangan |
|---|---|
| Tangkap layar penuh, termasuk URL browser | Memotong sampai hanya angka "100%" |
| Pastikan teks terbaca jelas | Foto layar pakai kamera HP |
| PNG atau JPG | Screenshot buram atau gelap |

:::danger Jangan pernah mengedit screenshot
Mengubah angka persentase atau memalsukan tampilan penyelesaian adalah **kecurangan** dan membatalkan kelulusanmu sepenuhnya.

Progress-mu juga tercatat di sisi platform — screenshot hanya untuk mempercepat verifikasi, bukan satu-satunya sumber. Memalsukannya tidak akan berhasil dan hanya merusak reputasimu di komunitas.

Kalau kamu belum 100%, **kejar penyelesaiannya**, jangan palsukan buktinya.
:::

## 3️⃣ Wallet Address

Kirim alamat Injective-mu.

**Format:** dimulai dengan `inj1...`

```
Contoh: inj1qwerty0987asdfgh1234zxcvbn5678poiuytre
```

:::warning Ini alamat yang dipakai untuk mengirim hadiah dan sertifikat
Periksa ulang dengan teliti:
- Pastikan alamatnya **milikmu** dan kamu punya akses ke seed phrase-nya
- **Salin-tempel**, jangan ketik manual
- Jangan pakai alamat exchange — pakai wallet pribadimu

Kalau alamatnya salah, sertifikat atau hadiah bisa terkirim ke tempat yang tidak bisa kamu akses, dan itu tidak bisa dibatalkan.
:::

:::info Kalau form meminta alamat `0x...`
Beberapa field mungkin meminta alamat EVM. Baca label field-nya dengan teliti dan berikan format yang diminta. Kalau ragu, tanya di grup Telegram — jangan menebak.
:::

---

## 4️⃣ & 5️⃣ Username Telegram dan Discord

**Telegram:** buka Settings → Username. Kirim dalam format `@username`.

Kalau kamu belum punya username (hanya nomor telepon), **buat sekarang** — panitia tidak bisa mencocokkan kehadiranmu di grup tanpa itu.

**Discord:** klik namamu di kiri bawah aplikasi Discord untuk menyalin username.

:::warning Username harus yang benar-benar kamu pakai di grup CLC11
Kalau kamu mengirim username berbeda dari yang ada di grup, panitia tidak bisa memverifikasi partisipasimu, dan syarat nomor 2 dianggap tidak terpenuhi.
:::

## 6️⃣ Post Refleksi X

**Yang harus ada dalam post:**
- Apa yang kamu pelajari
- Fitur Injective favoritmu dan alasannya
- Tag `@HackQuest_` dan `@Injective`

**Yang dikirim:** URL langsung ke post-nya (bukan ke profilmu).

### Contoh post yang kuat

> Baru selesai Co-Learning Camp #11 bareng @HackQuest_ Indonesia, belajar bangun di @Injective.
>
> Hal yang paling mengubah cara saya berpikir: orderbook Injective ada di level chain, bukan di dalam smart contract tiap aplikasi. Jadi dApp baru tidak mulai dari orderbook kosong — langsung nyambung ke likuiditas yang sudah ada.
>
> Saya deploy contract Solidity + CosmWasm, lalu bangun app target tabungan di atasnya.
>
> [screenshot]

Bandingkan dengan:

> Terima kasih @HackQuest_ dan @Injective atas campnya! Belajar banyak! 🚀🚀

Keduanya memenuhi syarat. Hanya satu yang menunjukkan kamu benar-benar paham sesuatu.

:::tip Post-mu bisa dibaca orang dari ekosistem
Tim HackQuest dan Injective memantau tag mereka. Post yang berisi kadang berujung pada percakapan, undangan, atau peluang.

Ini bagian submission dengan rasio manfaat-terhadap-usaha tertinggi. Sisihkan sepuluh menit untuk menulisnya dengan baik.
:::

:::warning Jangan hapus post-nya setelah submission
Panitia memverifikasi tautan setelah deadline. Post yang sudah dihapus atau akun yang dikunci akan membuat syarat ini dianggap tidak terpenuhi.
:::

## 7️⃣–9️⃣ Bukti Guided Project

| Item | Yang harus dipastikan |
|---|---|
| **Repo GitHub** | **Publik**, ada README, tidak ada file `.env` atau key |
| **Video demo** | 2–3 menit, tautan bisa dibuka publik |
| **Aplikasi online** | URL berjalan, tidak hanya localhost |

:::danger Tiga kesalahan paling umum
1. **Repo GitHub masih private.** Reviewer membukanya dan melihat 404. Buka Settings → General → Change visibility → Public.
2. **Tautan Google Drive masih dibatasi.** Ubah ke "Anyone with the link can view", lalu **uji di jendela penyamaran**.
3. **File `.env` ikut ter-commit.** Jalankan `git log --all --full-history -- .env` untuk memeriksa. Kalau ada, anggap key-nya bocor dan buat wallet baru.
:::

## 📝 Menyiapkan Submission

Buat satu dokumen berisi semuanya sebelum membuka form:

```
SUBMISSION CLC11 — [Namamu]

1. Profil HackQuest : https://www.hackquest.io/u/...
2. Screenshot 100%  : [file screenshot-track.png]
3. Wallet address   : inj1...
4. Telegram         : @username
5. Discord          : username
6. Post X           : https://x.com/.../status/...
7. GitHub           : https://github.com/.../celengan-target
8. Video demo       : https://youtu.be/...
9. Aplikasi         : https://celengan-target.vercel.app
```

:::tip Kenapa menyiapkan dulu di dokumen terpisah
Form biasanya tidak menyimpan progress. Kalau kamu mencari-cari tautan sambil mengisi, satu kali refresh bisa menghapus semuanya.

Siapkan semua, lalu tinggal salin-tempel dalam dua menit.
:::

## ✅ Checklist Akhir

Sebelum menekan tombol kirim:

- [ ] Semua tautan **diuji di jendela penyamaran**
- [ ] Repo GitHub sudah **publik**
- [ ] Tidak ada `.env`, private key, atau seed phrase di repo
- [ ] Screenshot jelas terbaca dan **tidak diedit**
- [ ] Wallet address **disalin-tempel**, bukan diketik
- [ ] Username Telegram sama dengan yang ada di grup CLC11
- [ ] Post X sudah live dan **tidak akan dihapus**
- [ ] Video demo bisa diputar orang lain
- [ ] Learning Track benar-benar **100%**, bukan 95%

:::warning Kirim lebih awal
Kirim pada **9 Agustus**, bukan 10 Agustus.

Kalau ada yang bermasalah — tautan rusak, screenshot ditolak, field salah — kamu masih punya waktu memperbaikinya. Submission yang dikirim satu jam sebelum deadline tidak punya ruang untuk kesalahan.
:::

## 🎯 Rangkuman

:::tip Yang Harus Kamu Ingat
- **Uji setiap tautan di jendela penyamaran** — ini penyebab kegagalan nomor satu
- Repo GitHub harus **publik** dan **bersih dari rahasia**
- Screenshot **jangan pernah diedit** — progress juga tercatat di sisi platform
- Wallet address **disalin-tempel**; salah alamat = hadiah hilang
- Username Telegram harus cocok dengan yang di grup
- **Post X yang spesifik** jauh lebih berharga daripada yang generik
- Siapkan semua tautan di satu dokumen sebelum membuka form
- **Kirim 9 Agustus**, sisakan penyangga satu hari
:::
